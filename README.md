# TechStore API

API REST desenvolvida com Node.js, TypeScript, Express e TypeORM.

## Tecnologias

- Node.js
- TypeScript
- Express
- PostgreSQL
- TypeORM
- JWT
- Bcrypt
- Nodemailer

## Instalação

npm install

## Executar

npm run build
npm start

## Desenvolvimento

npm run dev
As entidades internas foram mantidas para preservar a estrutura, os relacionamentos e o funcionamento da aplicação.
